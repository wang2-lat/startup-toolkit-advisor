# 创业者工具推荐+需求验证助手

## 功能

1. **工具推荐** - 根据预算和团队规模推荐最优工具组合
2. **需求验证** - 自动生成针对性调研问卷
3. **成本对比** - 对比不同方案的月度/年度成本
4. **获客指南** - 提供业务类型对应的获客渠道

## 使用

### 1. 获取工具推荐


交互式输入：
- 每月预算（元）
- 团队人数
- 业务类型

输出：
- 推荐工具列表（按类别）
- 每个工具的成本和功能
- 总成本和剩余预算

### 2. 生成需求验证问卷


交互式输入：
- 业务类型（B2B SaaS/电商/本地服务/内容教育）
- 产品/服务名称

输出：
- 5个核心验证问题
- 使用建议（样本量、关注点）

### 3. 成本对比


交互式输入：
- 每月预算
- 团队人数

输出：
- 4种方案对比表（免费/基础/专业/企业）
- 月成本、年成本、包含工具

### 4. 获客渠道指南


输出：
- 4种业务类型的获客渠道清单
- 避坑指南

## 核心解决的问题

1. **需求验证难** → 提供结构化问卷模板，避免盲目开发
2. **工具选择难** → 基于预算和场景自动匹配最优组合
3. **获客渠道不清晰** → 提供业务类型对应的渠道清单

## 扩展建议

- 添加更多工具到 `TOOLS_DB`
- 自定义问卷模板
- 集成真实工具API获取最新价格
- 添加工具使用教程链接

## 风险点

- 工具价格可能变动，需定期更新数据库
- 问卷模板需根据实际反馈迭代
- 获客渠道有时效性，需关注行业趋势

## 验证方式

- 推荐的工具组合是否在预算内
- 问卷是否能获得可执行的反馈
- 成本计算是否准确
